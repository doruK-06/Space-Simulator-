# Space-Simulator-
GRAV_MATRIX v3.0, hiçbir harici kütüphane, oyun motoru, CDN veya hazır ses/görsel dosyası kullanmadan; tamamen Vanilla JavaScript, HTML5 Canvas ve Web Audio API ile tek bir index.html dosyası içinde çalışan interaktif bir N-Cisim (N-Body) Kütleçekim, Relativistik Astrofizik ve Uzay Mühendisliği Simülasyonudur.
